# Контур — обзор сигналов

Интерактивный интерфейс-концепт для ручной проверки публичных сигналов о возможных угрозах жизни и здоровью. Проект пока представляет собой фронтенд-прототип для обсуждения MVP: он не подключается к соцсетям, не собирает данные и не делает выводов о реальных людях.

## Запуск

Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Что показывает прототип

- Очередь сигналов с поиском и фильтром по приоритету.
- Карточку выбранного сигнала с демо-фрагментом, источником и причинами для проверки.
- Действия аналитика: взять сигнал на проверку или отметить нерелевантным.
- Явную пометку, что все записи синтетические, а приоритет не является вероятностью вреда или оценкой опасности человека.

## Границы MVP

В качестве первого этапа предлагается проверять только сообщения из заранее определённых публичных источников. Система должна сохранять ссылку и минимальный фрагмент, нужный для проверки; группировать повторяющиеся сигналы; объяснять, какие признаки сработали; давать специалисту возможность зафиксировать контекст и решение. Автоматические санкции, скрытое наблюдение, поиск частных данных и автоматическое профилирование людей не входят в концепцию.

Перед подключением реальных источников потребуется отдельно определить законные основания, допустимые источники, сроки хранения, права доступа, удаление данных и процедуру эскалации непосредственной угрозы. Текущий демонстрационный интерфейс этих процессов не реализует.
